# Godly Spawner for Murder Mystery 2

This project provides a user interface and server-side script to spawn godlys in the popular Roblox game Murder Mystery 2. The scripts allow players to spawn godlys with a simple button click, enhancing the game's experience with additional features.

## Install

1. Download the project files from the GitHub repository.
2. In Roblox Studio, open your Murder Mystery 2 game.
3. Place the `IdidHub.lua` script in the `StarterPlayerScripts` folder.
4. Place the `GodlySpawner.lua` script in the `ServerScriptService` folder.

## Use

1. Launch the game in Roblox Studio or on a Roblox server.
2. Players will see a UI with a "Spawn Godly" button.
3. Clicking the button will spawn a godly at the player's location.
