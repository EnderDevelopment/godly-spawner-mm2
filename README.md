# Murder Mystery 2 Godly Spawner

This project provides scripts for spawning godlys in Murder Mystery 2, a popular Roblox game. It includes a user interface (UI) for players to spawn godlys and server-side logic to handle the spawning process. The scripts are designed to be easy to install and use, enhancing the gameplay experience in Murder Mystery 2.

## Install

1. Download the project files from the GitHub repository.
2. Open your Roblox Studio and load the Murder Mystery 2 game.
3. Place the `GodlySpawnerUI.lua` script in the `StarterPlayerScripts` folder.
4. Place the `GodlySpawner.lua` script in the `ServerScriptService` folder.

## Use

1. Launch the game in Roblox Studio.
2. Play as a player and you will see a UI with a "Spawn Godly" button.
3. Click the "Spawn Godly" button to spawn a godly in the game world.
